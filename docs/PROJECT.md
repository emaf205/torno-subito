# PROJECT NOTES

## Titolo

**TORNO SUBITO**

## Prima incarnazione

**Ferramenta Valenti — dal 1970 tutto per la casa**

## Finzione narrativa

Una piccola ferramenta italiana decide, nei primi anni 2000, di avere un sito Internet.

Il figlio del proprietario è l'unico della famiglia che sa abbastanza di computer da costruirlo. Non conosce però le convenzioni dell'e-commerce. Trasferisce quindi online la logica della bottega fisica: insegna, catalogo, telefono, orari, pausa pranzo, domenica e chiusura serale.

Nessun personaggio considera questa scelta strana.

## Stati dell'opera

- **APERTO** — sito navigabile, “cassa” disponibile.
- **PAUSA PRANZO** — saracinesca parzialmente abbassata; resta una fessura.
- **CHIUSO** — saracinesca completa.
- **RIPOSO SETTIMANALE** — domenica chiuso.
- **TRANSIZIONE** — se l'utente è dentro al momento della chiusura, la serranda scende davanti a lui.

## Tempo naturale

Il sito modifica progressivamente luminosità e temperatura visiva in base all'ora e alla stagione.

- alba;
- giorno;
- tramonto;
- notte.

Il tempo non è decorazione: è materiale dell'opera.

## Linguaggio visivo

Web commerciale italiano 2001–2003, credibile e non caricaturale:

- layout fisso;
- Internet Explorer;
- Verdana / Arial / Georgia;
- link blu e viola;
- pulsanti in rilievo;
- marquee;
- contatore visite;
- badge NOVITÀ / OFFERTA;
- “Best viewed at 1024×768”;
- piccoli errori e ingenuità familiari.

## Tecnologia

Un solo file:

`site/index.php`

PHP 5.6+ / HTML / CSS / JavaScript.

Nessun framework.  
Nessun database.  
Nessuna API esterna.

Timezone: `Europe/Rome`.

Gli stati di apertura, pausa, chiusura, riposo e ciclo luce sono documentati in `STATES.md`.
